About this demonstration

VIPERS HOSPITAL is a demonstration configuration of open-source hospital software, prepared for evaluation by prospective hospital clients. It contains fictional data only and is not a production clinical system.

Built on open-source software

This system runs unmodified official releases of the following projects. They are developed by their respective communities, not by Motion Imprints Technologies, and are used under the licences published in each project.

  • Bahmni (Bahmni Lite 2.0 distribution) - hospital information system. Source: github.com/Bahmni. Deployment configuration from Bahmni/bahmni-docker (MIT License, © OpenMRS Inc.).
  • OpenMRS - medical record platform. Source: github.com/openmrs. OpenMRS is a registered trademark of OpenMRS Inc.
  • Crater - invoicing and billing (Bahmni fork: Bahmni/crater).
  • Supporting components including MySQL, Apache HTTP Server, Node.js and Caddy, each under its own licence.
  • Background photograph by Alessio Soggetti on Unsplash (Unsplash License).

What Motion Imprints Technologies configured
