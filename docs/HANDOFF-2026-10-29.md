## 4. How to verify locally (Windows sandbox limits)

Node suites run fine locally (`APP=edge/addons`). `unit-ops.py` and your `.py` harness need Linux bash/flock/sha256sum —
the Windows Git Bash runtime fails (known); run them in a Linux container instead:
`docker run --rm -v <repo>:/k:ro python:3.12-slim sh -c 'apt-get update -qq && apt-get install -y -qq jq >/dev/null && python3 /k/tests/unit-ops.py'`.
Cloud/server state (images, VMs, IAM, deployed hashes) cannot be checked from the sandbox; it is reported here and in
the response doc.
